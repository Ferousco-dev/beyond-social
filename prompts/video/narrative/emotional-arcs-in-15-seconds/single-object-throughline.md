A single physical object, tracked through setup, turn, and resolution, gives a compressed arc a spine the audience can follow without any narration, and gives whoever is writing the prompt a concrete, checkable throughline instead of an abstract instruction like "show longing."

- Introduce the object in a clean, legible shot during setup, close enough that its detail is readable.
- Let it sit present but unremarked during the rest of setup, held or nearby, not yet meaningful.
- Change its state or location exactly at the turn: it changes hands, it's set down, it's picked back up, it breaks.
- Recontextualize it at resolution: same object, new meaning, ideally in a different part of the frame or a different light.
- Never introduce a new significant object only at the resolution.

Why: object continuity does double duty. Narratively it gives the audience a concrete thing to project meaning onto, which is cheaper and faster than reading an abstract emotional state off a face alone. Practically, naming one object explicitly across all three beats gives a generation prompt a consistency anchor, since the model has one instructed detail to keep matching rather than an unwritten expectation.

Example: "coffee mug with her initials, introduced close-up in setup; at the turn, mug set down on the far side of the table; resolution, same mug now on the windowsill, filled with cut flowers."
Counter-example: a ring appears in the final shot with no prior setup, so the resolution asks the audience to assign meaning to an object they've never seen, which reads as unearned rather than resolved.
