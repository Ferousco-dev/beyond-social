A rack focus shifts the focal plane from one subject to another within a
single shot, and naming it in a prompt is how to get a deliberate reveal or
attention shift instead of two separate static shots cut together.

- Name the start and end focal points explicitly: "focus starts on the hand
  reaching for the product, racks to the product label as the hand lifts it
  into frame."
- Use a shallow aperture (f/1.8-f/2.8) for the pull to read clearly, since a
  deep-focus frame has nothing to visibly shift.
- Keep the pull to one clear transition per shot; racking focus back and forth
  multiple times in a few seconds reads as showy rather than motivated.
- Reserve rack focus for a genuine narrative beat (a reveal, a reaction, a
  new detail entering the story), not as decoration, since an unmotivated
  focus pull draws attention to the camera technique instead of the subject.

Why: a focus pull is one of the few camera moves whose entire function is
directing the viewer's eye without a cut, which reads as intentional
filmmaking when it is tied to a story beat, and as an aimless effect when it
isn't, so the prompt should always name what the pull is revealing or
connecting, not just that a pull happens.

Example: "shallow focus at f/2, rack focus from the barista's hands pouring
to the customer's face lighting up as they taste it."
Counter-example: "focus pull for style" with no named subjects on either end
gives the model nothing to motivate the shift, producing a pull that looks
like a random blur sweep rather than a directed reveal.
