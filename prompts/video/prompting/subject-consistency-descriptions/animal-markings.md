An animal's identity is carried almost entirely by coat pattern and marking
placement, so those need the same landmark-based description used for human
imperfections, not a breed name alone.

- Describe the base coat color, then the pattern type using accurate vocabulary
  — brindle, tabby, patched, roan — rather than just "spotted" or "colorful."
- Anchor at least one marking to a specific location: a white patch over the
  left eye, a black sock on the right hind leg.
- Note ear shape and carriage (erect, half-erect, floppy) and tail carriage,
  since generic prompting tends to flatten these breed-specific details.
- Keep behavior and expression description separate from the marking
  description so the two don't blur together between shots.

Why: unlike a human subject, an animal has no name or backstory for the viewer to
lean on for continuity — pattern and marking placement are the only visual signal
that says "this is the same animal" across cuts, so they carry more identity
weight than almost any other descriptor in the prompt.

Example: "a brindle-coated dog, white patch over the left eye, one white front
paw, ears held half-erect, tail carried low."

Counter-example: "a cute brown dog" — no pattern, no marking location, no ear or
tail carriage, so every regeneration can plausibly be read as a different animal.
