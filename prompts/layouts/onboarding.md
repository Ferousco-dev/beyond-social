Good onboarding gets the user to one real outcome as fast as possible, then gets
out of the way. Prefer doing over telling: a guided first action beats a carousel
of feature tours that everyone skips.

Principles: ask only for what you need to deliver the first win, defer the rest to
progressive disclosure. Show progress if the flow is more than two steps. Make
every step skippable but make the happy path obviously best. On mobile, respect
safe areas and keep primary actions in the thumb zone.

Why: activation is driven by time-to-first-value, not by how much the user was
told. Front-loaded forms and multi-screen tours increase drop-off at exactly the
moment intent is highest.

Example: a two-step flow, pick a goal then generate a first result from a sample,
with a thin progress bar and a "Skip for now" text link. Counter-example: a
five-slide feature carousel followed by a twelve-field profile form before the
user has seen anything work.
