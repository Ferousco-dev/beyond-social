In long-form text, where the F-pattern's later rows get progressively less
complete reads, a pull quote or bolded callout acts as a forced re-entry
point. It resets attention mid-article by introducing new visual weight the
eye can't skim past on the way down.

The recipe:

- Place one pull quote roughly every 400-600 words, timed just before the
  point where F-pattern decay would otherwise lose the reader.
- Pull the actual highest-value sentence from the surrounding paragraph, not a
  generic summary line; it has to reward the interruption or it reads as
  filler.
- Size it distinctly from both body and headings so it isn't mistaken for a
  subhead being skimmed for structure rather than read for content.
- Never stack two pull quotes back to back; each one spends some of the
  reader's willingness to be interrupted.

Why: the F-pattern isn't a fixed geometric law, it's a description of what
happens when nothing on the page fights attention decay. A pull quote works
by momentarily converting a skim-mode reader back into a read-mode reader at
the one spot the argument most needs to land.

Example: mid-article, set off in larger italic type: "The team cut incident
response time by 70% without adding headcount."
Counter-example: a pull quote reading "As mentioned above, this next section
covers our methodology." It costs the reader an interruption and returns
nothing, so the next decay point arrives faster, not slower.
